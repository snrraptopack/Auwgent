# Changelog - January 28, 2026

## Runtime + DX Fixes

### Overview
Restored manual model override support, aligned driver routing with model names, and fixed streaming output consistency when tools are involved.

### Plan
- Allow per-run model overrides across run and streaming APIs
- Route driver selection by modelName consistently
- Normalize structured output handling between stream and non-stream

### Changes
- Added modelOverride support in RunConfig and generated types for run/stream/streamIterable/forContext
- Routed drivers using DriverRegistry resolution by modelName, with provider fallback
- Aligned streaming tool removal with non-streaming to ensure structured output on final turn
- Made structured output parsing strict (invalid JSON now throws)
- Fixed OpenAI driver model selection to prefer config.modelName
- Normalized Google driver name to gemini

### Files Modified
- javascript/loader/IrInterpreter.ts
- javascript/loader/drivers/OpenAIDriver.ts
- javascript/loader/drivers/GoogleDriver.ts
- packages/cli/src/Types/typesGenerator.ts
- Generated types: type-system-test.agent.types.ts, test-autoreg.agent.types.ts
