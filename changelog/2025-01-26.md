# Changelog - 2025-01-26

## Auto Model Registration Feature

### DSL Changes
- New model provider syntax: `model: gemini("gemini-2.0-flash")`, `model: openai("gpt-4")`, `model: custom("url", "model")`
- Replaces old `model: "model-name"` string syntax

## Lifecycle Hooks Feature

### Added
- Lifecycle hooks system for conversation memory management
- Three hooks: `prune`, `load`, `save`
- `prune`: Decides what to keep in context (summarization point)
- `load`: Fetches prepared messages from storage
- `save`: Persists new messages after agent run

### Usage
```typescript
const lifecycle: TestAutoRegLifecycle = {
    prune: async ({ context, usage }) => ({ messages: [] }),
    load: async ({ context }) => ({ messages: memoryStore.get(context.chatId) ?? [] }),
    save: async ({ newMessages, context, output }) => {
        memoryStore.set(context.chatId, [...existing, ...newMessages]);
    }
};

agent.run(input, context, lifecycle);
```

### Fixed
- Lifecycle hooks now work in both `run()` and `stream()` modes

### Architecture Refactoring
- **Removed DriverRegistry** - Agent now accepts simple `Record<string, AgentDriver>` directly
- Factory functions auto-create drivers from API keys
- Simplified from 3 abstraction layers to 1

### Generated Types Changes
- New `{AgentName}ApiKeys` interface generated based on required providers
- Factory accepts `{ geminiApiKey: "..." }` instead of manual DriverRegistry setup
- Driver imports auto-generated based on DSL providers

### IR Changes
- `Config.modelName: string` → `Config.model: ModelProvider`
- `ModelProvider = { type: "gemini" | "openai" | "custom", modelName: string, url?: string }`

### Files Changed
- `auwgent.langium` - New grammar for model providers
- `ir.ts` - ModelProvider union type
- `agentConfig.ts` - extractModelProvider function
- `IrInterpreter.ts` - drivers map instead of DriverRegistry
- `typesGenerator.ts` - ApiKeys interface, auto-registration
- `Synthesizer.ts` - getModelProvider returns full provider info
- `GoogleDriver.ts` - Uses config.modelName for API calls

### Lifecycle Bug Found
- Lifecycle hooks (prune, load, save) not called in streaming mode
- Only works in `run()`, not in `stream()`
