# Changelog - 2026-01-27

## DSL String Concatenation & Enhanced Prompting

### Added
- **String Concatenation Operator (`+`)**: Support for combining named prompts, strings, and inline prompt blocks using the `+` operator.
- **Improved Prompt References**: Named prompts can now be referenced directly inside `config` blocks and mixed with other expressions.
- **Inline Prompt Blocks**: Ability to use `{ ... }` blocks containing prompt statements (strings, if-statements) anywhere an expression is expected.

### Usage Example
```
prompt base { "You are a helpful assistant." }

agent MyAgent {
    default config {
        model: gemini("gemini-2.0-flash")
        prompt: base + " Be very concise." + { "Keep it professional." }
    }
}
```

### Files Changed
- `auwgent.langium`: Updated grammar with `BinaryExpression`, `AdditionExpression`, and extended `Referenceable` to include `NamedPrompt`.
- `generator.ts`: Added IR generation for `concat`, `promptRef`, and `inlinePrompt`.
- `agentConfig.ts`: Updated `extractPrompt` to handle expression-based prompts.
- `Synthesizer.ts`: Added runtime resolution for new prompt expression types.

## Gemini Streaming Consistency

### Refined
- **Gemini Structured Output Streaming**: Restored original behavior where JSON schema is enabled for streaming when no tools are present. This ensures that the `onText` callback receives raw JSON chunks including property keys (e.g., `{"reply": "..."}`), which allows for richer streaming interaction despite the "raw" formatting. 

### Files Changed
- `GoogleDriver.ts`: Reverted explicit disabling of JSON schema for streaming to support field-aware chunks as requested.
