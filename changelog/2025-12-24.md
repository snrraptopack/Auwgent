# Changelog - 2025-12-24

## Added

### True Async Streaming
- Converted workflow pipeline to use true async generators
- `ExpressionEvaluator.evaluateStream()` - yields chunks immediately
- `WorkflowRunner.runStream()` - async generator for workflows
- `IrInterpreter.runStream()` - private streaming method
- **Fluent `stream()` API** for clean callback-based streaming:
  ```typescript
  const result = await agent
    .stream({ request: "Create a dashboard" })
    .onText(delta => process.stdout.write(delta))
    .onHelperStart(name => console.log(`>>> ${name}`))
    .onHelperEnd((name, result) => { /* capture result */ })
    .onTransfer((helper, mode) => { /* track transfers */ })
    .run();
  ```

### StreamBuilder (`javascript/loader/StreamBuilder.ts`)
- Fluent callback API for streaming agent execution
- Handlers: `onText`, `onToolStart`, `onToolEnd`, `onToolResult`, `onHelperStart`, `onHelperEnd`, `onHelperChunk`, `onTransfer`, `onChunk`

### Logger System (`javascript/loader/Logger.ts`)
- Configurable log levels: `NONE`, `ERROR`, `WARN`, `INFO`, `DEBUG`, `TRACE`
- Token usage tracking (prompt, completion, total)
- Call statistics tracking (helpers, workflows, tools)
- `logger.printStats()` for end-of-run summary

### Property Access in DSL
- Grammar: `MemberAccess` expression type added
- Syntax: `design.propose` to access nested properties
- Scope provider updated to resolve `grantedTools` references

### Future Features Documentation (`docs/FUTURE_FEATURES.md`)
- Parallel Agents
- Shared Context
- Conditional Routing
- Retry/Fallback
- Agent Memory
- Output Validation
- Token Budgets

## Changed

### Logging Cleanup
- Replaced all `console.log` with `logger.debug()` in:
  - `IrInterpreter.ts`
  - `ExpressionEvaluator.ts`
  - `OpenAIDriver.ts`
- Production mode now only shows `INFO` level and above
- Development debugging available via `logger.setLevel(LogLevel.DEBUG)`

### OpenAI Driver
- Now tracks token usage from API responses
- Logs token counts at DEBUG level
