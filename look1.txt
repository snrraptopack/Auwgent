response_text:
  text: |
    Here's what's going wrong, Theophilus:

    Your `await` inside `.forEach` is silently doing nothing useful. forEach doesn't know
    about promises — it just fires each callback and moves on. By the time your data arrives,
    the outer function has already returned.

    Fix option 1: for...of
    ----------------------
    for (const item of items) {
      const result = await fetchData(item)  // this actually waits now
      results.push(result)
    }

    Fix option 2: Promise.all
    -------------------------
    const results = await Promise.all(
      items.map(async (item) => {
        const result = await fetchData(item)
        return result
      })
    )

    Key difference: for...of is sequential — each fetch waits for the previous.
    Promise.all fires all fetches simultaneously and waits for all to finish.
    If order matters and one failure should stop everything: use for...of.
    If speed matters and failures can be handled individually: use Promise.all.

    The "undefined is not iterable" you're seeing: that's coming from line 14 where you
    destructure `data.results` — by that point data is still a pending Promise object,
    not the resolved value. The await above it got swallowed by forEach so it never
    actually resolved before line 14 ran.
