# `#[auwgent_tools]` — Type Safety Design

## The problem with a free impl block

`#[auwgent_tools]` on a free `impl MyTools` is **not type-safe by itself**.
The macro can only see what's there — it cannot know what's *supposed* to be there.

```rust
// DSL declares: get_location, get_user_name_age
// User forgets get_location entirely

#[auwgent_tools]
impl MyTools {
    async fn get_user_name_age(&self) -> Person {
        Person { name: "Theo".into(), age: 99 }
    }
    // ← get_location silently missing
    // compiles fine, breaks at runtime
}
```

Same problem with a wrong return type — the macro has no reference signature
to check against, so it serialises whatever it gets and the LLM gets confused.

---

## Fix — code generator emits a trait, macro goes on the impl

The code generator emits a trait from your `.auwgent` DSL file. You never write this:

```rust
// generated by auwgent codegen
#[async_trait]
pub trait HelloTools: Send + Sync {
    async fn get_location(&self) -> String;
    async fn get_user_name_age(&self) -> Person;
    // every tool declared in the DSL becomes a required method
}
```

The user then implements that trait, and `#[auwgent_tools]` goes on the impl:

```rust
struct MyTools;

#[auwgent_tools] // macro now has a reference signature to validate against
impl HelloTools for MyTools {
    /// Returns the user's current location
    async fn get_location(&self) -> String {
        "Tarkwa".to_string()
    }

    /// Returns the user's name and age
    async fn get_user_name_age(&self) -> Person {
        Person { name: "Theophilus".into(), age: 99 }
    }
}
```

- Miss a method → `rustc` error
- Wrong return type → `rustc` error
- Doc comments still flow to the macro for LLM-visible descriptions

---

## Params DX — typed args, not raw JSON

Without generated typed signatures the user has to deserialise manually:

```rust
async fn search(&self, args: Value) -> String {
    let q = args["query"].as_str().unwrap();
    let limit = args["limit"].as_u64().unwrap() as usize;
    // verbose, panic-prone, no IDE help
    todo!()
}
```

With a generated trait the DSL type maps to a real Rust type in the signature:

```rust
// DSL: search(query: string, limit: int)
// generated trait method:
//   async fn search(&self, query: String, limit: u32) -> String;

async fn search(&self, query: String, limit: u32) -> String {
    // runtime deserialises JSON args → typed params
    // user never touches serde here
    todo!()
}
```

## What the macro actually generates

```rust
// #[auwgent_tools] generates behind the scenes:

impl AuwgentToolDispatch for MyTools {
    fn tool_manifest() -> &'static [ToolDef] {
        &[
            ToolDef {
                name: "get_location",
                description: "Returns the user's current location", // ← from ///
                schema: /* schemars::schema_for!(String) */,
            },
            ToolDef {
                name: "get_user_name_age",
                description: "Returns the user's name and age",
                schema: /* schemars::schema_for!(Person) */,
            },
        ]
    }

    async fn dispatch(&self, name: &str, args: Value) -> ToolResult {
        match name {
            "get_location"      => ToolResult::ok(self.get_location().await),
            "get_user_name_age" => ToolResult::ok(self.get_user_name_age().await),
            _ => ToolResult::not_found(name),
        }
    }
}
```

The dispatch table is exhaustive and statically verified because it mirrors
the trait methods exactly. The user never writes any of this.

## Responsibility split

| Layer | Responsibility |
|---|---|
| Code generator | Emits `trait HelloTools` with exact signatures from the DSL |
| `#[auwgent_tools]` | Harvests `///` docs, generates `tool_manifest()` + `dispatch()` |
| `rustc` | Enforces completeness — missing or wrong-typed methods are compile errors |
| Runtime | Deserialises LLM JSON args into typed method params via `serde` |

async fn main() -> anyhow::Result<()> {

struct MLogger;

#[async_trait]
impl AuwgentMiddleware for MLogger {
    fn name(&self) -> &str { "simple logger" }

    async fn on_run_start(&self, session: Session, _ctx: &Context) -> Session {
        println!("{session:#?}");

    }
