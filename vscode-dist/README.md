# Auwgent VS Code Extension

This directory contains the pre-compiled `.vsix` file for the Auwgent VS Code extension. This extension provides syntax highlighting and language support for the `.agent` DSL.

## Installation

To install the extension manually in Visual Studio Code:

1.  Open **Visual Studio Code**.
2.  Go to the **Extensions** view by clicking on the square icon on the left sidebar (or press `Ctrl+Shift+X`).
3.  Click on the **"..."** (More Actions) menu at the top-right corner of the Extensions panel.
4.  Select **"Install from VSIX..."**.
5.  Browse to find the `auwgent-vscode-0.1.1.vsix` file in this folder and select **Install**.
6.  Restart VS Code if prompted.

## Features

- **Syntax Highlighting**: Full syntax highlighting for `.agent` files.
- **Language Integration**: Seamless development experience with the Auwgent CLI and SDK.
